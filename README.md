# 山河足迹

中国地级行政区旅行地图，原作者：Cloudchaser_dyq。

## 使用

1. 创建本站账号，保存注册后显示的恢复码。好友 ID 在「好友」页显示，用户名和密码用于登录。
2. 在「图层」中选择图层，再点击城市加入或移出。每座城市可属于多个图层，重叠区域用条纹显示。
3. 勾选「计入去过」的图层参与足迹统计和好友比较。「想去」及其他主题图层可独立保存。
4. 「集合」支持交集、并集、差集、对称差、补集和两者之外。结果可以存为新图层。
5. 在「好友」中输入好友 ID 发送申请。双方确认后，可以查看共同去过、都未去过、任一去过及各自独有的区域。
6. 切换「照片随笔」，点击城市，发布照片和文字，选择「公开」或「好友可见」。登录用户可以评论可访问的记录。

拖拽可从城市或空白处开始；拖拽不会误标记城市。滚轮缩放，右侧复位按钮恢复全国视图，背景色可以自行选择。

## 从旧版迁移

先在旧 HTML 中「导出配色 JSON」，再在新版「图层 → 导入、备份与导出」中导入。每种颜色转为独立图层，保留颜色备注和显示状态。JSON 备份包含地图图层；照片、随笔、好友关系和评论保存在服务器中，未包含在图层备份内。

访客草稿保存在当前浏览器。首次创建空账号时会带入当前访客地图。已有账号优先载入其云端图层；其他设备同时修改时，会让用户选择保留本机版本或载入云端版本，本机可先导出备份。

## 运行与构建

需要 Node.js 24 或更高版本，pnpm。

```sh
pnpm install --frozen-lockfile
pnpm test
pnpm dev
```

本机地址为 `http://127.0.0.1:4317`。本地 SQLite 数据库和照片位于 `.task-tmp/local-data/`，与云端数据独立。开发服务器仅监听本机；测试不会预置账号。生产入口为 `worker/index.mjs`。

```sh
pnpm build
```

构建输出：`dist/server/index.js`，包含网页、脚本、样式和地图数据，不依赖外部 CDN。数据库迁移源为 `db/schema.js`，生成命令 `pnpm db:generate`；生产迁移位于 `drizzle/`，本地初始模式位于 `migrations/0001.sql`。

## 存储与身份

- D1 绑定 `DB`：账号、密码派生值、会话摘要、好友关系、图层、随笔、评论。
- R2 绑定 `BUCKET`：照片。图片由鉴权接口读取，好友可见照片不直接公开存储地址。
- 本站账号独立注册，不使用微信或 ChatGPT 作为应用登录方式。
- 密码使用带随机盐的 PBKDF2-SHA256；会话和恢复码只存摘要。生产会话 Cookie 为 Secure、HttpOnly、SameSite=Lax。
- 找回密码需要注册时保存的恢复码；重置会撤销旧会话并产生新恢复码。
- 站点需开放访客入口，本站账号登录才能供外部好友使用。Sites 控制台的访问边界与本站账号权限分别生效。

## 数据来源与验证

地图来源：阿里云 DataV GeoAtlas 公共边界数据。`scripts/prepare-map.mjs` 可重新生成数据。保留原版地级区域筛选规则；直辖市、港澳台按原版整体处理。共 340 个可选区域，另保留 35 条省区及辅助边界。辅助几何不计入可填行政区。
